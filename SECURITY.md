# Security policy

This repository contains public documentation and no production service code.

If you believe the repository exposes sensitive information or creates a security risk, do not open a public issue and do not include exploit details in an X message. Contact CodeVolt through [codevolt.co.uk](https://codevolt.co.uk), state that the message concerns a private security report, and initially provide only enough information to arrange a safe follow-up route.

Never send credentials, private keys, customer data or live access details through a public channel.
