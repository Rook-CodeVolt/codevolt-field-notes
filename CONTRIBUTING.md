# Contributing

Focused corrections that make these public documents clearer or more accurate are welcome.

Before opening an issue or pull request:

1. Read [`PUBLICATION_POLICY.md`](PUBLICATION_POLICY.md).
2. Do not include customer information, credentials, private system details, security findings or material copied from private work.
3. Keep the change small and explain the reader benefit.
4. Run `python3 scripts/validate_public_content.py .`.
5. Update [`CHANGELOG.md`](CHANGELOG.md) for a user-visible change.

For a sensitive concern, follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue. Work enquiries belong on [codevolt.co.uk](https://codevolt.co.uk).
